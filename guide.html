우리 학교 수능 응원 페이지 만들기

선생님, 후배, 학부모님이 쓴 응원 편지를 모아 3학년 학생들에게 보여 주는 웹페이지입니다. 수능 날 준비물, 시간표, 4교시 순서 안내도 함께 들어 있습니다. 비용은 들지 않고, 처음 한 번 20분쯤 걸립니다.

준비물 구글 계정, GitHub 계정(github.com에서 무료 가입)필요한 주소 아래 세 가지

준비하기

  1. 시트 복사하기

    템플릿 주소를 열고 사본 만들기를 누릅니다. 내 구글 드라이브에 응답 시트 사본이 생깁니다.

    템플릿: docs.google.com/spreadsheets/d/17wH9hABh8IRBjUlfn_y-Z1ZqmSGrqwPA-zwBa6zo3sI/copy

  2. 설문 만들기

    복사된 시트 위쪽 메뉴에서 수능 응원 → 설문 만들기를 누릅니다(메뉴가 안 보이면 새로고침). 처음 한 번은 권한 확인 창과 함께 경고 문구가 나오는데, 무시하고 진행하면 됩니다. 계속 → 내 계정 선택 → 「Google에서 확인하지 않은 앱」 화면에서 고급 → 수능 응원 설문 만들기(으)로 이동 → 허용을 누릅니다. 승인한 뒤 메뉴를 한 번 더 누르면 설문이 만들어지고, 창에 나온 설문 응답자 링크를 복사해 둡니다.

  3. 「공개용」 탭만 웹에 게시하기

    복사된 시트에서 파일 → 공유 → 웹에 게시를 엽니다. 게시된 콘텐츠 및 설정에서 「공개용」 하나만 고르고, 링크는 공개용 · 쉼표로 구분된 값(.csv)로 바꾼 뒤 게시합니다. 나온 주소를 복사해 둡니다.

  4. 내 페이지 저장소 만들기

    GitHub에 로그인하고 아래 주소를 엽니다. Repository name에 영어 이름(예: suneung-2027)을 쓰고 Public을 고른 뒤 Create repository를 누릅니다.

    github.com/dossamlab/suneung-cheer-kit/generate

  5. 설정 넣기

    설정 만들기 화면에 2번과 3번의 주소를 붙여 넣고 시트 연결 확인 → 내용 복사를 누릅니다. 내 저장소에서 config.js를 열고 연필 모양(Edit)을 눌러 내용을 모두 지운 뒤 붙여 넣고 Commit changes를 누릅니다.

    설정 만들기: dossamlab.github.io/suneung-cheer-kit/make.html

  6. 배포 켜기

    내 저장소의 Settings → Pages에서 Branch를 main, 폴더를 / (root)로 고르고 Save를 누릅니다. 1~2분 뒤 https://내아이디.github.io/저장소이름/ 이 우리 학교 주소가 됩니다. 이 주소를 학생과 학부모님께 보냅니다.

운영하기

  • 편지가 오면 응답 시트의 「반영」 칸을 체크한 편지만 페이지에 붙습니다. 체크하고 5~10분 뒤에 보입니다.
  • 체크를 풀면 페이지에서 내려갑니다. 부적절한 글은 체크하지 않으면 됩니다.
  • 「시험 끝난 뒤 축하」 편지는 11월 19일 16:37에 화면이 열립니다.
  • 탭은 시각에 맞춰 전날 밤, 아침, 시험 중, 끝난 뒤로 저절로 넘어갑니다.

꼭 지켜 주세요

  • 웹에 게시할 때 전체 문서가 아니라 「공개용」 탭 하나만 고릅니다. 전체를 게시하면 체크하지 않은 편지까지 공개됩니다.
  • 「공개용」 탭의 수식, 응답 시트의 열 이름과 순서, 설문 선택지 문구는 바꾸지 않습니다.
  • 권한 확인 창의 경고는 직접 만든 스크립트라 나오는 것입니다. 스크립트는 선생님 계정으로 이 시트 안에서만 동작하고 바깥으로 정보를 보내지 않습니다.
  • 카톡 미리보기가 옛것으로 나오면 주소 끝에 ?v=2를 붙여 보냅니다.
